# custom-cards/

Images du jeu de cartes personnalisé, envoyées depuis l'appli (salon → « 🃏 Jeu de cartes
personnalisé ») et stockées ici par le serveur de l'hôte : `AS.jpg`, `10H.png`, `back.jpg`…
(code « rang + couleur », `back` pour le dos). Le contenu de ce dossier n'est pas versionné.
Pour tout effacer à la main : supprimer les fichiers puis relancer le serveur.
